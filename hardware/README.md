# Habico hardware

This will be the folder where all hardware related code and assets will live.

## Structue

- case/
  - Contains the 3D model files for the case of the Habico device.
- test-load-cell/
  - Contains prototype code for tesconnecting load cell to microcontroller
- firmware/
  - Contains the firmware code for the Habico device, including microcontroller code and any necessary libraries.
